📖 Quick Guide

1. Deploy: Run ./scripts/deploy.sh to deploy the infrastructure.

2. Get URL: Copy the api_url output and paste above.

3. Get Key: Run terraform output -raw api_key and paste above.

4. Spec: OpenAPI defaults to /openapi.json (from static S3 website).

5. Test: Use the sidebar to test each endpoint interactively.

Endpoints:

  • GET /health — Check system status (no auth required)
  • POST /reports — Submit a disaster report
  • GET /reports?status=PENDING_REVIEW — List reports
  • GET /reports/{id} — Get report details
  • PATCH /reports/{id} — Verify/reject a report
  • DELETE /reports/{id} — Soft delete a report
  • GET /reports/stats — Dashboard statistics
