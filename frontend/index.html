🚀 Features

ความสามารถหลักของระบบ Report Ingestion & Verification

📥

High-Throughput Ingestion

รับข้อมูลรายงานจาก Social Media, Mobile Apps, IoT Sensors ผ่าน REST API พร้อมส่งเข้า SQS Queue ทันที (Fire-and-Forget)

🤖

AI Trust Scoring

ใช้ Google Gemini API วิเคราะห์ความน่าเชื่อถือ จำแนกประเภทเหตุการณ์ ตรวจจับ Spam อัตโนมัติ (<30% = SPAM)

📈

Deduplication

ลดความซ้ำซ้อนด้วย Haversine Formula (GPS ≤200m), Time Window (≤15min) และ External ID Check ผ่าน GSI

✅

Verification Workflow

State Machine ครบวงจร: RECEIVED → PENDING_REVIEW → VERIFIED/SPAM/REJECTED/DUPLICATE พร้อม Optimistic Locking

📢

Event-Driven Architecture

EventBridge Custom Bus สำหรับ broadcast เหตุการณ์ ReportVerifiedEvent, ReportStatusChangedEvent ไปยัง downstream services

📊

Real-time Dashboard Stats

สถิติแบบ Pre-aggregated ผ่าน Atomic Counter Table อ่านข้อมูลระดับ milliseconds ไม่ Scan ตารางหลัก

🖥 API Endpoints

Base URL: {API_GATEWAY_URL}/v1

Method Path Description Auth
POST /reports Submit raw disaster report (Fire-and-Forget via SQS) X-Api-Key
GET /reports List pending reports (with pagination & filters) X-Api-Key
GET /reports/{id} Get report detail (AI analysis, metadata, verification) X-Api-Key
PATCH /reports/{id} Verify/reject report (with state transition validation) X-Api-Key
DELETE /reports/{id} Soft delete report (Audit logged) X-Api-Key
GET /reports/stats Dashboard summary (Atomic Counter based) X-Api-Key
GET /health Health check (DynamoDB, SQS, Gemini, EventBridge) Public
